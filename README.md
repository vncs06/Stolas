# Stolas — Book Translation Editorial

Skill do Codex para tradução editorial contextual de PDFs com preservação de elementos gráficos, glossário e QA visual.

Instalação: copie os arquivos para `~/.codex/skills/book-translation-editorial/`.

**Status:** protocolo editorial em desenvolvimento. Não é um motor autônomo de tradução e diagramação. Não publique PDFs protegidos por direitos autorais.
